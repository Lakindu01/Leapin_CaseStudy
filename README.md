# Leapin_CaseStudy
## Overview

The service manages:

- Organisations (tenants)
- Members
- Funding Periods
- Service Categories and Service Items
- Contribution Rates
- Invoices and Claims
- Funding Balances / Ledger Entries
- Quarterly Finalisation Jobs

## Project Goals

The primary objectives of this project are:

- Implement claim and contribution calculation rules
- Validate funding balances before claim approval
- Support tenant isolation
- Demonstrate clean TypeScript architecture
- Provide automated testing
- Deploy using AWS serverless services
- Expose OpenAPI documentation directly from the application
